# Libras Studio Desktop

Aplicativo desktop do Libras Studio.

Arquitetura atual:
- frontend: HTML/CSS/JavaScript em WebView;
- backend: Python;
- persistência local: SQLite;
- integração opcional: AnkiConnect;
- nuvem: Supabase.

Os dados reais do usuário ficam fora do código-fonte e não devem ser enviados ao GitHub.
