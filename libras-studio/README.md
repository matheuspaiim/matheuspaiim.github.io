# Libras Studio

Projeto do Libras Studio: estudo, biblioteca, revisão espaçada e integração entre desktop e celular.

## Estrutura

- `/libras-studio/` — versão web/mobile publicada pelo GitHub Pages.
- `/libras-studio/desktop/` — código-fonte da versão desktop em Python + WebView.
- `/libras-studio/android/` — código do APK Android, quando sincronizado.

## Links

- Repositório: https://github.com/matheuspaiim/matheuspaiim.github.io/tree/main/libras-studio
